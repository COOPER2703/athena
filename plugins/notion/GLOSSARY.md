# Plugin Notion — glossaire

Vocabulaire de pages qui n'appartient qu'au plugin `notion`. Le vocabulaire du contrat
(Plugin, Tool de plugin, Instruction de plugin) et les termes du noyau restent au
glossaire racine ; `GLOSSARY-MAP.md` dit où trouver chaque contexte.

**Page Notion**:
Une page du workspace Notion, seule unité que le plugin `notion` lit et modifie. Une base
de données ou une data source n'est pas une Page.
_Avoid_: Note, fiche, document, page web
